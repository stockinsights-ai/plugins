# Get started with stockinsights.ai India

Explain that a stockinsights.ai account is required. If the connection is not active, ask the user to sign in through the stockinsights.ai prompt shown when they first use a plugin tool. Do not request credentials in chat.

Once connected, invite the user to start with a company or research question. Examples:

- How has TCS revenue changed over the last eight reported quarters?
- Which mid-cap pharma companies have the highest ROE?
- What did Infosys management say about deal wins in its latest earnings call?

Use the `stock-research` skill for the chosen question. If the tools remain unavailable after sign-in, tell the user to reconnect or re-authorise the stockinsights.ai India connection.
